# 🎮 GameVault — Sistema de Gestão de Locadora e Loja de Jogos

O **GameVault** é um sistema para gerenciamento completo de uma locadora e loja de jogos eletrônicos. O sistema controla o catálogo de títulos, plataformas suportadas, cadastro de clientes e o fluxo de operações comerciais (locação e venda).

Este projeto foi desenvolvido como requisito prático para a disciplina de **Introdução à Programação 2 (IP2)**.

---

## 🚀 Funcionalidades Principais

- **Gerenciamento de Catálogo:** Cadastro, atualização e controle de disponibilidade de jogos e plataformas.
- **Enriquecimento via API Externa:** Conexão com API pública de catálogo de jogos para preenchimento automático de dados (gênero, plataformas e desenvolvedora/publicadora).
- **Gestão de Clientes e Planos:** Cadastro de usuários com validação de regras de negócio, como verificação de faixa etária (classificação indicativa) e controle de limites de locações simultâneas de acordo com o plano do cliente.
- **Operações Comerciais:** Registro e controle de empréstimos, devoluções e vendas diretas de jogos.

---
